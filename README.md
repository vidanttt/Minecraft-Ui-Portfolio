# Portfolio Edition

A personal portfolio that plays like a block-game title screen. Each menu button opens a real route with its own game-style screen.

| Route | Screen |
| --- | --- |
| `/` | Title screen: voxel panorama, stone wordmark, splash text, main menu |
| `/about` | Player Profile: avatar, statistics, abilities, milestones, visitor advancements |
| `/projects` | Select World: searchable world list (click selects, double-click / Enter / Play enters) |
| `/projects/[slug]` | A world: artwork, info, objective, tech, screenshots, links |
| `/skills` | Inventory: category tabs, item slots, tooltips, equipped slots |
| `/socials` | Play Multiplayer: socials as servers |
| `/contact` | Book and Quill: validated contact form |
| `/settings` | Options: volume, sounds, music, graphics, GUI scale, animations |

## Run it

```bash
npm install
npm run dev
```

`npm run build` creates the production build and `npm run lint` runs ESLint.

## Edit your content

All personal content lives in `lib/data/`. Anything in `[brackets]` is a placeholder.

- `lib/data/profile.ts`: name, intro, quest, abilities, interests, milestones, avatar colours
- `lib/data/projects.ts`: worlds. Images go in `public/images/projects/`. A missing `liveUrl` or `sourceUrl` disables its button.
- `lib/data/skills.ts`: inventory items, pre-filled from this site's own stack. Remove anything you don't use.
- `lib/data/socials.ts`: add real profile URLs. Entries without a URL show "Can't connect to server".
- `lib/data/site.ts`: wordmark, edition banner, splash texts, version label, optional `contactEmail` (mailto fallback), `siteUrl`

## Contact form

`app/api/contact/route.ts` validates input, rate-limits each IP, ignores honeypot spam and delivers the message through **one** of these (see `.env.example`):

- `RESEND_API_KEY` + `CONTACT_TO_EMAIL` (optional `CONTACT_FROM_EMAIL`)
- `CONTACT_WEBHOOK_URL`

With neither set, the form tells visitors the message service isn't set up. It never pretends a message was sent.

## How it's built

- **Next.js 16 App Router** (Cache Components + Partial Prefetching), React 19, strict TypeScript, Tailwind CSS v4
- **Design system** in `app/globals.css`. Everything is measured in GUI pixels (`--gui`, 2–4px depending on the viewport or the GUI Scale option), and Tailwind spacing is mapped to it.
- **Font**: *Blockfolio*, an original pixel font generated by `tools/font/make_font.py` (fontTools). Edit the glyph bitmaps there and re-run it.
- **Panorama**: `lib/panorama/terrain.ts` generates a seeded voxel world (face culling, ambient occlusion); `lib/panorama/engine.ts` renders it with Three.js. It runs on the shared `gsap.ticker`, drops to about 30fps and half resolution behind menus, renders a single frame when motion is reduced, and falls back to a static CSS landscape without WebGL.
- **Motion**: GSAP handles screen entrances, the loading overlay, advancement toasts and dialogs (`lib/animation/`). Lenis smooths the long scroll areas only (profile, world details). Buttons and tooltips respond instantly, like the game.
- **Audio**: `lib/audio/game-audio.ts` creates one AudioContext after the first user gesture, decodes each sample once, throttles repeats and can generate optional ambient music (off by default). The original effects come from `tools/audio/make_sounds.py`.
- **Textures**: the original 16x16 art comes from `tools/textures/make_textures.py`.
- **State**: settings and visitor advancements are saved in `localStorage` through `lib/settings/store.ts`.

### Keyboard

`Esc` goes back to the previous screen. Arrow keys move through menus, lists and the inventory grid. `Enter` selects.
